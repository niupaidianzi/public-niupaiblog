用 Cloudflare Pages 白嫖一个个人博客

2026-10-12 · 牛排

一直想有个自己的博客，但不想付服务器钱，也不想维护后端。试了一圈之后发现：静态站 + Cloudflare Pages 就是白嫖的终极答案。

为什么选 Cloudflare Pages？

免费额度非常慷慨：无限带宽、无限请求数（Pages 静态托管本身不限量），全球 CDN，自动 HTTPS。对于个人博客这种纯静态场景，基本等于永久免费。

我的策略：所有交互都放在前端 —— 主题切换用 localStorage，访问计数也用 localStorage，完全不碰 Workers，省下每日 10 万次的后端额度留给真正需要的功能。

部署只要三步

# 1. 把静态文件推到 GitHub 仓库
git add . && git commit -m "blog" && git push

# 2. Cloudflare Dashboard → Pages → Connect to Git
#    构建命令留空（纯静态），输出目录填 /

# 3. 等待 30 秒，拿到 xxx.pages.dev 域名 🎉

踩坑记录

单文件不能超过 25MB，图片记得压缩。我用 webp 格式存头像，jpeg 存封面，整站加起来不到 200KB，加载飞快。

另外注意相对路径要写对，Pages 没有目录索引回退时记得每个目录放 index.html。
